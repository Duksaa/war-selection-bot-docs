# Privacy Policy for War Selection Official Bot

**Effective Date:** April 2024

This Privacy Policy explains how the War Selection Official Bot ("Bot") processes information. Our priority is user privacy, and we do not store your data outside of Discord.

## 1. Data Processing (No Storage)
The Bot processes the following data in real-time to provide moderation and logging services:
- **Message Content:** Used solely to detect deleted/edited messages and to filter prohibited words (anti-spam/anti-toxic). 
- **User & Server IDs:** Used only to identify users within the server's own moderation logs.

**Important:** We do not store any of this data on external servers, databases, or any off-platform storage. All processing happens in the Bot's temporary memory (RAM) and is discarded immediately after the action is performed.

## 2. How We Use the Message Content Intent
We use this intent exclusively for:
- **Instant Logging:** Displaying a log of deleted or edited messages directly in a designated channel within your server so moderators can maintain a safe environment.
- **Auto-moderation:** Checking messages against server-specific filters to prevent harassment.
- **No AI Training:** We do not use any message content to train machine learning or AI models.

## 3. Data Retention
Since we do not store data off-platform, there is no data retention. Logs exist only within the Discord channels where the server administrators choose to post them.

## 4. User Privacy & Opt-out
- The Bot does **not** track or read Direct Messages (DMs).
- Users can avoid being logged by Discord-native methods (leaving the server or contacting server staff to disable logging in specific channels).

## 5. Contact
If you have questions, please contact **duksaa** on Discord.
