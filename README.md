# Privacy Policy for War Selection Official Bot

**Effective Date:** April 2026

This Privacy Policy explains how our Discord bot ("Bot") collects, uses, and protects your information.

## 1. Information We Collect
The Bot processes the following data to provide moderation and logging services:
- **Message Content:** Used solely for logging deleted/edited messages and automated moderation (filtering).
- **User IDs & Names:** To identify users in moderation logs.
- **Server IDs:** To store server-specific settings.

## 2. How We Use Data
We use the Message Content Intent to:
- Log deleted and edited messages for server administrators to prevent harassment.
- Filter spam and prohibited words based on server rules.
- **We do not** use this data for marketing, profiling, or training AI models.

## 3. Data Storage and Retention
- Logs are stored securely and are only accessible by authorized server staff.
- Message content is stored for a maximum of 30 days, after which it is automatically deleted.

## 4. User Rights and Opt-out
Users can opt-out of message logging by:
- Contacting the server administrator to request data removal.
- Leaving servers where the Bot is active.
- The Bot does not track Direct Messages (DMs).

## 5. Contact
If you have questions, please contact duksaa.
